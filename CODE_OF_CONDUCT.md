# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussions about the work,
and do not harass anyone. Maintainers may remove comments, commits, issues or
contributors that do not follow it.

Report unacceptable behaviour privately to the maintainers through the
repository's security contact in [SECURITY.md](SECURITY.md).
