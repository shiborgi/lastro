# ADR 10: A Quiet Review Interface

**Status:** Accepted (0.1.0)

## Context

The agent does most of the work; the web app is where a person reviews and corrects it.

## Decision

- Hierarchy comes from layout, not chrome. Financial figures use `tabular-nums`. Colour is never the only signal; every state is named in text.
- Selected MIT components from the shadcn/ui registry are copied with attribution in `THIRD_PARTY_NOTICES.md`; the registry is not a dependency.

## Consequences

- Screens stay dense and predictable, and the notice check keeps attribution honest.
